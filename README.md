## ✨ About The Project

**Cogno OS** is an advanced, client-side operating system environment running entirely in your browser. Designed with stunning macOS-inspired glassmorphism aesthetics, fluid animations, and real OS-level features, it serves as an interactive playground showcasing modern web development capabilities.

It is built from the ground up to be fast, responsive, and persistent, storing your files and preferences locally in your browser.

## 🚀 Features

- 🖥️ **Window Management System**: Fully draggable, resizable, maximizing, and minimizing windows with Z-index handling.
- 📂 **Virtual File System (VFS)**: Powered by `IndexedDB`, providing persistent folder and file storage across sessions.
- 🎨 **Dynamic Personalization**: Instantly switch between Light & Dark modes, change accent colors, and set custom wallpapers.
- 🔒 **Native Lock Screen**: Complete with a boot-up sequence, animated password prompt, and a stunning idle clock view.
- ⌨️ **Functional Terminal**: Run simulated commands (`ls`, `cd`, `mkdir`, `echo`, `theme`, `open`, `neofetch`, and more).
- 🧩 **Slide-over Widget Panel**: Access calendar, storage stats, and a fully functional calculator widget at a glance.
- 📱 **Mobile Responsive**: Intelligently handles window constraints and full-screen snapping on mobile devices.
- 🌐 **Web Apps Integration**: Pin your favorite external websites to your Taskbar and Start Menu.

## 📦 Built-in Applications

1. **Terminal**: A powerful CLI emulator to interact with the Virtual File System.
2. **File Manager**: A graphical explorer to browse, create, and manage your local data.
3. **Text Editor**: A simple, sleek editor to write and save documents to the VFS.
4. **Settings**: Central hub to manage security, appearance, wallpapers, and VFS data.
5. **Browser**: An iframe-based browser to surf the web within the OS.
6. **Calculator**: A clean, animated calculator app for quick math.

## 💻 Local Development

Want to run Cogno OS locally or contribute to the project? Follow these steps:

### Prerequisites
Make sure you have Node.js (v18+) installed on your machine.

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/abhiraj1121/cogno-os.git
   ```
2. Navigate into the project directory
   ```bash
   cd cogno-os
   ```
3. Install NPM packages
   ```bash
   npm install
   ```
4. Start the Vite development server
   ```bash
   npm run dev
   ```
5. Open your browser and visit `http://localhost:5173`.
